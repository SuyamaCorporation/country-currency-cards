# 14 - 国と通貨暗記カード

**ビルド日**: 2026-11-03
**カテゴリ**: fun
**slug**: country-currency-cards

## 概要
33カ国以上の国名と通貨名称をフラッシュカードと4択クイズで学習できるSPA。地域別正解率グラフ付き。

## 機能
- 33カ国以上のデータ内蔵（アジア/ヨーロッパ/アメリカ/その他）
- フラッシュカードモード: 国名表示→クリックで通貨名・記号を確認
- 地域フィルター（アジア・ヨーロッパ・アメリカ・その他・全て）
- わかった/わからないボタンで進捗記録
- クイズモード: 国名から4択で通貨を選択
- 成績タブ: 地域ごとの正解率バーグラフ表示
- localStorage進捗保存
- 進捗リセットボタン
